# Beyond Fluency Lab

Communication coaching for fluent English speakers in Europe. Live, small-group practice for persuasion, interviews, presentations and performance under pressure.

This is the public site for [Beyond Fluency Lab](https://github.com/soumyakantabera/beyond-fluency), rebuilt with the studio identity:

- **Ink Navy** `#111A33` — type, navigation, primary buttons
- **Burgundy** `#7A2E3A` — italic emphasis, tags, secondary borders
- **Warm Gold** `#C9A227` — short marks and underlines only
- **Paper** `#F2F0EA` — page background

Headlines use **Fraunces**. Body text uses **Work Sans**.

## Local

```bash
npm install
npm run dev
```
